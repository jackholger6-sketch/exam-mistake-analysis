# 卷面判读与错因分类

## 一、红笔符号

| 符号 | 含义 | 判读陷阱 |
|---|---|---|
| 长弧线 ✓（有的老师一笔带过，像小斜线） | 对 | 弧线太长会穿过下一行，别误判成划掉 |
| ✗（两条交叉线） | 错 | 有的老师只点在答案旁，符号很小，必须放大 |
| 红色 `?` | **留白 / 没作答** | 这不是算错，是"没思路"。诊断要写"思维断点"，不能写"计算错误" |
| `−1 −2 −5 −10` | 扣分 | **最可靠的错题定位依据**，先找它 |
| 红色圆圈 | 圈出错误位置/漏读的条件 | 圈在某个数字上 = 那个数字被他当成别的数用了 |
| 红色订正（孩子用蓝笔抄老师写的答案） | 老师已讲过一遍 | 这类题孩子"当时懂了"，复习时更要重做 |

**定位口诀**：先找扣分数字 → 再找叉 → 再看问号 → 最后自己重算一遍确认。

## 二、三重校验（防止误判）

1. **符号层**：扣分/叉/问号落在哪道题上。
2. **笔迹层**：孩子写的答案到底是多少（`6` 和 `0`、`3` 和 `5` 在扫描件上极易混）。
3. **算术层**：自己把题算一遍，看正确答案与孩子答案差在哪一步。

只有三层都指向同一处，才写成"确定错题"。任一层模糊，就在报告里注明"按推断还原"。

## 三、错因分类（诊断时按这五类落笔）

| 类型 | 表现 | 典型话术 |
|---|---|---|
| **知识漏洞** | 概念本身没建立：估算规则、数位/倍、钝角锐角 | "把 X 理解成了 Y，实际应该是……" |
| **思维断点** | 概念懂，但中间缺一步推理 | "没有把『差』翻译成『份数差』" |
| **策略方向** | 方法选反：该往小估却往大估、该分组却直接乘 | "方向反了，估大得到的是上限" |
| **信息筛选** | 应用题多余条件、主语看错 | "问的是『同学采摘』，用的是『果园总产』" |
| **操作/习惯** | 会但没做对：没自查、没检验、留白 | "画完没有『是不是比直角大』这一眼" |

> 禁止只用「粗心」「不认真」下结论。它解释不了任何东西，家长也没法据此行动。

## 四、结论怎么写才诚实

先看分丢在哪个板块，再下判断：

- 口算/竖式/选择基本全对，分全丢在解决问题 → **"计算基本功没问题，别加练计算题"**，重点写审题与策略。
- 计算题成片错 → 才是基础问题，一周计划里放"每天 10 道竖式"。
- 同一类题反复错（3 处以上同模型）→ 单独列一条"高频漏洞"，复习表第 3 轮专门打它。

## 五、举一反三怎么出才算"同类型"

不是把数字换一换。同一道题要变**三个维度**之一：

1. **换情境**：果园采摘 → 商店进货；草柳编订单 → 礼堂座位。
2. **换问法**：问"一共多少" → 问"够不够"；"买 56 盒要多少钱" → "要得到 25 本最少花多少"。
3. **换模型位置**：正向算 → 反推；两个因数都取整 → 只取整一个（判断题）。

每组变式里放 1 道**判断题或说理题**，用来检验孩子是不是真懂，而不是套公式。
