## 字段要点

| 字段 | 必填 | 说明 |
|---|---|---|
| `meta.graded_date` | ✅ | 老师批改日期，复习表的起点。不明就问用户 |
| `meta.score` / `full_score` | ✅ | 用来核对 `sum(deduct)`，对不上就是漏了错题 |
| `errors[].no` | ✅ | 卷面题号原样写（`五、1（1）`），家长要能对上原卷 |
| `errors[].deduct` | ✅ | 数字，不带符号。总表自动渲染成 `-N` 红标 |
| `errors[].card_title` | ✅ | 一句话说清「卡在哪」，不要写「第 3 题错误」 |
| `errors[].question` | ✅ | 原题 HTML，尽量完整抄，可含选项 |
| `errors[].image` | 建议 | 卷面证据图；没有就整块不渲染 |
| `errors[].diagnosis` | ✅ | 三层：知识漏洞 / 思维断点 / 习惯问题 |
| `errors[].practice` | ✅ | 3～4 题 |
| `errors[].answers` | ✅ | 与 practice 顺序一一对应，出现在最后一页 |
| `bars` | 建议 | 按题型归并扣分，`points` 自动按最大值归一化 |

## 写作要求（决定报告好不好用）

1. **`card_title` 是对家长的翻译**：`"够不够"的估算：要往小估，不是往大估` 好过 `估算策略错误`。
2. **`diagnosis` 不要出现"粗心"**：粗心是结论不是原因。要么是"没看个位就能排除"这样的方法缺失，要么是"画完没有回头看一眼"这样的动作缺失。
3. **`teach_steps` 用动词开头**：对、找、连、查 / 定一组、求组数、算要付几盒、算钱。
4. **`practice` 要有梯度**：前 1～2 题贴着原题模型，后 1～2 题换情境（买赠换到"要得到多少本"这种反向问法）。
5. **`answers` 要带过程**，不只是一个数——孩子看答案是为了学会怎么想。
